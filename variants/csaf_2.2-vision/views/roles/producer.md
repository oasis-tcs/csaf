# Producer

Creates or changes CSAF Documents: writes them by hand or tool, converts from other formats, translates, withdraws or supersedes them.

Conformance targets: 2: CSAF Producer, 3: CSAF Direct Producer, 4: CSAF Converter, 5: CVRF CSAF Converter, 6: CSAF Content Management System, 7: CSAF Post-Processor, 8: CSAF Modifier, 9: CSAF Translator, 18: CSAF 2.0 to CSAF 2.1 Converter, 19: CSAF Library, 20: CSAF Library with Basic Validation, 21: CSAF Library with Extended Validation, 22: CSAF Library with Full Validation, 24: CSAF Withdrawer, 25: CSAF Superseder, 26: CSAF RVISC ID Updater, CSAF Publisher.
