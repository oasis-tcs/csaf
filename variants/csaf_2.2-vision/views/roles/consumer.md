# Consumer

Reads CSAF Documents and acts on them: displays them, matches them against assets or SBOMs, and derives (automated) decisions from them.

Conformance targets: 6: CSAF Content Management System, 7: CSAF Post-Processor, 8: CSAF Modifier, 9: CSAF Translator, 10: CSAF Consumer, 11: CSAF Viewer, 12: CSAF Management System, 13: CSAF Asset Matching System, 17: CSAF SBOM Matching System, 19: CSAF Library, 20: CSAF Library with Basic Validation, 21: CSAF Library with Extended Validation, 22: CSAF Library with Full Validation, 24: CSAF Withdrawer, 25: CSAF Superseder, 26: CSAF RVISC ID Updater.
