# Comment Resolution Log

The table summarizes the comments that were received during the 15-day public review of the committee specification draft "[Common Security Advisory Framework Version 2.1](https://docs.oasis-open.org/csaf/csaf/v2.1/csd03/csaf-v2.1-csd03.html)" and their resolution. Comments came to the csaf-comment and the CSAF TC mailing lists. [The public review did start 2026-09-15 at 00:00 UTC and did end 2026-09-29 at 23:59 UTC](https://groups.oasis-open.org/discussion/invitation-to-comment-on-common-security-advisory-framework-version-21-csd03-ends-29-sept-2).

A status of "Completed" in the Disposition column indicates that the editors have implemented the changes on which the TC decided, which are outlined in the Resolution column. It also is a hyperlink to the GitHub commit notice.

The item number is a hyperlink to the e-mail on the csaf-comment or CSAF TC mailing lists.

## Evaluation of Feedback

The TC considers above public comments as well as other more editorial feedback documented in issue [#1639](https://github.com/oasis-tcs/csaf/issues/1639) and classified/considered per pull request [#1640](https://github.com/oasis-tcs/csaf/pull/1640) as **Material** per OASIS TC process.

To ease verification by anyone and to support the administration this comment resolution log is provided as an individual document as per this artifact.
